# Saqlangan dizayn

Asl dizayn yo‘nalishi: oq fon, qora asosiy tugmalar, ixcham sidebar, nozik chegaralar, yirik sanalar va tabular taymer raqamlari. Imtihonlar va study kategoriyalaridagi ko‘k accent hamda jadvaldagi qizil/yashil holatlar asl fayldagidek saqlangan.

`original.html` — foydalanuvchi bergan faylning o‘zgartirilmagan nusxasi. `src/styles/original.css` — uning CSS’i, o‘qishga qulay formatlangan. `src/styles/product.css` — hisob, sync holati, klaviatura focus va mobil shell uchun kichik qo‘shimchalar.
